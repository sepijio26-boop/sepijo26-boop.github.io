# 🦘 Auto Jump Reset — مود ماینکرفت

یه مود **کاملاً کلاینتی** که تنظیم **Auto Jump** رو هر تیک چک می‌کنه و اگه روشن شده باشه،
فوراً **خاموشش می‌کنه (ریست به OFF)**.

> Auto Jump همون قابلیتیه که وقتی راه می‌ری و به یه بلوک می‌خوری، خودکار می‌پری بالا.
> خیلی‌ها (مخصوصاً تو PvP) ازش بدم می‌آن، ولی بعضی سرورها/کلاینت‌ها یا باگ خود بازی
> دوباره روشنش می‌کنن. این مود دیگه نمی‌ذاره روشن بمونه.

---

## 📦 فایل‌های آماده (بدون نیاز به بیلد)

توی پوشه‌ی [`jars/`](jars/) دو تا jar از قبل ساخته شده:

| فایل | برای چی | چطور نصب می‌شه |
|---|---|---|
| `AutoJumpReset-1.8.9-Forge.jar` | ماینکرفت **۱.۸.۹** (هر لانچر Forge — حتی آفلاین/کرک) | بریز توی پوشه‌ی `mods` |
| `AutoJumpReset-1.21.1-Fabric.jar` | ماینکرفت **۱.۲۱.۱** — **توی Lunar هم کار می‌کنه** | توی پروفایل Fabric لانچرت بریز توی پوشه‌ی مودها |

---

## ⚠️ نکته‌ی خیلی مهم درباره‌ی Lunar Client و ۱.۸.۹

قبل از هر کاری اینو بدون که **دو تا گزینه‌ی جدا** داری:

1. **اگه می‌خوای ۱.۸.۹ بازی کنی (PvP کلاسیک):**
   Lunar Client توی نسخه‌ی ۱.۸.۹ **مود دلخواه لود نمی‌کنه** — اون گزینه‌ی Forge که توی
   لانچر Lunar هست فقط برای یه سری مود خاص اسکای‌بلاکِ خودِ Lunar هست، نه مودهای شخصی.
   پس برای استفاده از این مود توی ۱.۸.۹، با یه **لانچر Forge معمولی** (مثلاً Forge رسمی،
   Prism Launcher یا هر لانچر آفلاینی که پشتیبونیش می‌کنه) بازی کن و jar فورج رو توی پوشه‌ی
   `mods` بنداز. همه‌ی امکانات مود کار می‌کنه.

2. **اگه می‌خوای **توی خود Lunar** بازی کنی:**
   Lunar از نسخه‌های جدیدتر (۱.۱۶.۵ به بالا، مثل **۱.۲۱.۱**) پروفایل **Fabric** داره و
   مودهای Fabric دلخواه رو لود می‌کنه. برای همین نسخه‌ی Fabric همین مود (۱.۲۱.۱) رو
   ساختم که **توی Lunar هم کار کنه**. کافیه:
   - لانچر Lunar رو باز کن و نسخه‌ی **۱.۲۱.۱** رو انتخاب کن؛
   - اگه توی تنظیمات پروفایل گزینه‌ی نصب مود/فولدر مود هست، jar رو اونجا بنداز
     (یا از بخش مودهای لانچر اضافه‌ش کن)؛
   - اگه توی نسخه‌ی لانچرت این گزینه نبود، با یه لانچر Fabric معمولی (لانچر رسمی
     ماینکرفت + نصب‌کننده‌ی Fabric، یا Prism Launcher) نسخه‌ی ۱.۲۱.۱ رو اجرا کن —
     همین jar توی اونجا هم درست کار می‌کنه.

> **راجع به «کرک» بودن:** این مود **هیچ چکی روی حساب یا پریمیوم بودن نمی‌کنه** و کاملاً
> سمت کلاینتِ. یعنی توی محیط‌های آفلاین/کرک هم دقیقاً مثل حالت عادی کار می‌کنه.
> فقط مراقب باش — کلاینت‌های کرک ناشناس می‌تونن بدافزار داشته باشن؛ اگه ممکنه از لانچر
> رسمی Lunar یا لانچرهای معتبر استفاده کن.

## 🚀 نصب سریع

### نسخه‌ی ۱.۸.۹ (Forge)

1. یه **Forge 1.8.9** نصب کن (یا لانچری که Forge داره).
2. فایل `jars/AutoJumpReset-1.8.9-Forge.jar` رو بذار توی پوشه‌ی **`mods`** ماینکرفت
   (معمولاً `%appdata%\.minecraft\mods` توی ویندوز).
3. بازی رو اجرا کن. تمومه! 🎉

### نسخه‌ی ۱.۲۱.۱ (Fabric — برای Lunar و بقیه)

1. پروفایل **Fabric 1.21.1** داشته باش (توی Lunar یا هر لانچر دیگه).
2. فایل `jars/AutoJumpReset-1.21.1-Fabric.jar` رو بذار توی پوشه‌ی مودها.
3. **نیازی به Fabric API یا هیچ مود دیگه‌ای نیست** — این مود بدون وابستگی‌ست.
4. بازی رو اجرا کن. وقتی Auto Jump روشن بشه، پیام «Auto Jump was reset to OFF»
   توی اکشن بار (بالای هات‌بار) میاد و خاموش می‌مونه.

## 🛠 بیلد از سورس

اگه می‌خوای خودت از سورس بسازی یا تغییرش بدی، دو تا پروژه‌ی مستقل توی ریپو هست:

### پروژه‌ی ۱: `AutoJumpReset-Forge-1.8.9/`

- **نیاز:** Java 8 (JDK) — با نسخه‌های جدیدتر ForgeGradle قدیمی کار نمی‌کنه
- **بیلد:**
  ```
  cd AutoJumpReset-Forge-1.8.9
  gradlew build          (ویندوز: gradlew.bat build)
  ```
- **خروجی:** `build/libs/AutoJumpReset-1.8.9-1.0.0.jar`
- ساختار: `build.gradle` (ForgeGradle 2.1) + `src/main/java/com/autojumpreset/AutoJumpReset.java`
- منطق: `@SubscribeEvent` روی `TickEvent.ClientTickEvent` → اگه `mc.gameSettings.autoJump`
  درست باشه، `false` می‌شه.

### پروژه‌ی ۲: `AutoJumpReset-Fabric-1.21.1/`

- **نیاز:** Java 21 (JDK)
- **بیلد:**
  ```
  cd AutoJumpReset-Fabric-1.21.1
  gradlew build          (ویندوز: gradlew.bat build)
  ```
- **خروجی:** `build/libs/AutoJumpReset-1.21.1-1.0.0.jar`
- ساختار: `build.gradle` (Fabric Loom + Yarn mappings) + میکسین توی
  `src/main/java/com/autojumpreset/mixin/AutoJumpResetMixin.java`
- منطق: میکسین روی `MinecraftClient#tick()` → اگه `client.options.autoJump.getValue()`
  درست باشه، `setValue(false)` می‌شه.
- نسخه‌ها توی `gradle.properties` هستن؛ برای تغییر نسخه‌ی ماینکرفت اون‌جا رو عوض کن
  (و اسم متدها رو با مپینگ اون نسخه چک کن).

## ⚙️ رفتار مود

- هر تیک (۲۰ بار در ثانیه) تنظیم Auto Jump چک می‌شه.
- به محض اینکه روشن بشه → خاموش می‌شه. یعنی **عملاً نمی‌تونی Auto Jump رو روشن نگه داری**.
- موقع هر ریست، یه پیام کوتاه میاد (حداکثر **هر ۵ ثانیه یک‌بار**، تا اسپم نشه).
- خاموش کردن مود = برداشتن jar از پوشه‌ی mods.

## ❓ سوالات متداول

**آیا این مود چیت محسوب می‌شه و بن می‌گیرم؟**
نه؛ فقط یه تنظیم بازی رو خاموش نگه می‌داره. ولی قبل از استفاده روی سرورها، قوانین اون
سرور رو چک کن.

**چرا Auto Jump خودش روشن می‌شه؟**
یه باگ معروف توی نسخه‌های قدیمی‌تر و بعضی کلاینت‌ها/سرورهاست که تنظیمات رو عوض می‌کنن.
این مود دقیقاً برای همین ساخته شده.

**روی نسخه‌ی دیگه‌ی ماینکرفت (مثلاً ۱.۲۰.۴) کار می‌کنه؟**
نسخه‌ی Fabric رو می‌تونی برای هر نسخه‌ی جدیدی بازسازی کنی: توی `gradle.properties`
نسخه‌ی `minecraft_version`، `yarn_mappings` و `loader_version` رو عوض کن (از
[فابریک‌دات‌نت/دِوِلپ](https://fabricmc.net/develop) نسخه‌ها رو ببین) و دوباره بیلد کن.

**پوشه‌ی mods توی Lunar کجاست؟**
توی لانچر Lunar معمولاً از تنظیمات پروفایل/نسخه می‌شه به پوشه‌ی بازی رسید. اگه گزینه‌ای
ندیدی، از بخش مودهای خود لانچر (اگه هست) اضافه کن یا از یه لانچر Fabric معمولی استفاده کن.
